## 一、已经查明的事实（别重复踩）

| 结论 | 证据 |
|---|---|
| CEF 154 **不会**因为 `Content-Disposition: attachment` 自动下载 | 本地 HTTP 服务发 attachment、GitHub zip 都被当网页渲染，`~/Downloads` 无文件、无 `on_before_download` |
| `<a download>` 也不触发 | 页面 JS 点链接，无动静 |
| **下载机制本身是好的** | 手动调 `BrowserHost::start_download` 后 HTTPS 下载成功：`download.html` 577B、`opencode-main.zip` 362K 均落盘，`on_before_download`/`on_download_updated` 都正常 |
| localhost 的 HTTP 下载会失败 | `interrupted=1 reason=20`（NETWORK_FAILED），HTTPS 完全正常——**这是已知边缘情况，不在本单必达范围，但要在回执里写明** |
| 该路径的 `log::info!` 进不了 journal | `handle_action` 里的日志实测不出现（`tabnew` 动作生效但无日志）。调试用直接写文件（见下） |
