# 派单：F-CEF-29 命令面板后端（Ctrl+K，小步单卡）

## 目标

Chrome/Brave 都有命令面板（Ctrl+K），本项目 CEF 版还没有。本卡只做**后端数据聚合 + 动作路由**，前端 DOM/JS 二狗接。

## 交付

新建 `src-tauri/src/engine/cef/palette_ui.rs`：

### 1. `palette_json(query: &str) -> String`

返回四组候选（JSON）：

```json
{
  "tabs":    [{"id":"shell-tab-1","title":"...","url":"..."}],
  "history": [{"title":"...","url":"...","visited_at":123}],
  "bookmarks":[{"title":"...","url":"..."}],
  "commands":[{"id":"newtab","label":"新建标签页","hint":"Ctrl+T"}]
}
```

规则：
- `query` 为空：tabs 全给、history/bookmarks 各 top 8（按时间倒序）、commands 全给
- `query` 非空：大小写不敏感子串匹配 title/url/label，每组最多 10 条
- 命令清单**硬编码在模块内**（单一来源），至少 8 条：
  `newtab`(Ctrl+T) / `closetab`(Ctrl+W) / `reopentab`(Ctrl+Shift+T) /
  `bookmarks`(Ctrl+Shift+O) / `history` / `downloads` / `settings` / `find`(Ctrl+F)
- 数据来源（**已核实存在，直接调，别新写 SQL**）：
  - `crate::db::history::list_recent(pool, limit)` → `Vec<HistoryEntry>`
  - `crate::db::history::search(pool, query, limit)` → `Vec<HistoryEntry>`
  - `crate::db::bookmarks::get_bookmarks_inner(pool)` → `Vec<Bookmark>`
  - 标签列表从 `super::shell` 的 `SHELL_TABS` 读（`lock_state` 是 `pub(crate)`）
- **不碰 BookmarkBar 的 UI 结构，只读库**

### 2. `handle(cmd: &str, arg: &str) -> bool`

- `"palette"` → 参数 `1` 打开 / `0` 关闭（留 TODO 给二狗接 `set_palette_panel`，先 `log::info` 桩）
- `"palettequery"` → `arg` 是查询词，查完经 `run_toolbar_js` 推 `window.__shiftPalette(json)`（**ref 用 `super::shell::run_toolbar_js`**）
- `"paletteexec"` → `arg` 是命令 id 或 `tab:<id>` / `url:<url>`，转调 `super::shell` 的现有动作（新标签/关标签/恢复/打开面板/导航）；**本卡只实现能直接复用的，不能复用的留 TODO 列出**

### 3. 单测（纯函数，≥4 例）

- 空 query：四组都在、history/bookmarks 各 ≤8、commands 全
- 非空 query：命中 title、命中 url、大小写不敏感
- 每组上限 10
- 空结果：四组都是空数组（不是 null）
