## 二、任务（两项，按顺序做）

### 1. 缩放（Ctrl+`+` / Ctrl+`-` / Ctrl+`0`）

- 靶子：`src-tauri/src/engine/cef/shell.rs` 的 `handle_shortcut`（约 1691 行）现在只处理
  Ctrl+T/W/Tab/Shift+T/Shift+B，在这后面加缩放。
- CEF API（已核，签名在 `cef` crate 154.5）：
  - `BrowserHost::set_zoom_level(zoom_level: f64)`
  - `BrowserHost::get_zoom_level() -> f64`
- 档位建议（Chrome 同款，CEF zoom level 0=100%，每 +1=120%）：
  `[-0.58, 0.0, 0.53, 1.14, 2.01, 2.65, 3.41]`
  对应 `90 / 100 / 110 / 125 / 150 / 175 / 200 %`。
  Ctrl+`+` 下一档、Ctrl+`-` 上一档、Ctrl+`0` 回 0。
- 工具栏要能看到当前百分比（放地址栏右侧或 ⋮ 菜单里都行，你定），
  用 `run_toolbar_js` 推 `window.__shiftZoom(pct)`。
- 注意：`=` 键（不按 Shift）通常就是 `+`，`handle_shortcut` 里要同时认 `=`/`+`。
- 只做当前标签，按站点记忆不做（P2）。

### 2. 页内查找（Ctrl+F）

- 工具栏加查找栏：输入框 + 计数（如 `3/17`）+ 上一个/下一个/关闭。
  放地址栏下方浮层；**注意工具栏是独立视图，浮层会被 122px 视口裁切**，
  参考 `set_bm_popup` / `set_dl_panel` 的撑高做法（`FIND_EXTRA` + `apply_toolbar_height`）。
- CEF API（已核）：
  - `BrowserHost::find(identifier: i32, search_text: &CefString, forward: i32, match_case: i32, find_next: i32)`
  - `BrowserHost::stop_finding(clear_selection: i32)`
  - `FindHandler::on_find_result(identifier, count: i32, selection_rect, active_match_ordinal: i32, final_update: i32)`
    → 推 `window.__shiftFind({count, active, final})` 给工具栏。
- 动作走现有 console 桥：`SHIFT_ACT:find|<text>`、`findnext`、`findprev`、`findclose`。
  **注意白名单**：内容页 console 只放行 6 个 ctx* 动作（见 `ShellContentDisplay::on_console_message`），
  查找动作从**工具栏**发（`ShellToolbarDisplay` 已放行全部 `SHIFT_ACT:`），别挂错 client。
- Enter = 下一个，Shift+Enter = 上一个，Esc = 关闭并 `stop_finding(1)`。
