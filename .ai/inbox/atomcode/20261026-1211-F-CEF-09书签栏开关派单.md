# F-CEF-09：书签栏开关（Ctrl+Shift+B）+ 动态工具栏高度

**范围很小，一轮必须交付。** 你前几轮都超时，这次只做这一件事。

## 现状

- 工具栏是 CEF 的一个 BrowserView，高度由 `shell.rs::TOOLBAR_HEIGHT = 122` 固定
- 122 = 标签栏 40 + 工具栏 48 + 书签栏 34，**书签栏常显**
- 高哥要求：能像 Chrome 一样用 `Ctrl+Shift+B` 收起/展开书签栏

## 目标

1. `Ctrl+Shift+B` 切换书签栏显示
2. 收起时视图高度变 88（40+48），展开时 122
3. 状态记在进程内存即可（不用持久化），默认展开
4. 收起时内容区自动变高（BoxLayout 会按新高度重算）

## 实现要点（已查证，照做）

- `shell.rs:29` `pub const TOOLBAR_HEIGHT: i32 = 122;` → 改成可变：
  用 `thread_local! { static TOOLBAR_H: Cell<i32> }` 或 `AtomicI32`，并提供 `fn toolbar_height() -> i32`
- 工具栏视图高度来自 `ShellViewDelegate::preferred_size()`（`shell.rs:176` 附近，返回
  `Size { width: 100, height: self.preferred_height }`），`preferred_height` 在
  `ShellViewDelegate::new(RuntimeStyle::ALLOY, TOOLBAR_HEIGHT)` 时传入——现在是常量，
  要改成每次显示/隐藏后重新设置视图 bounds 或重建 delegate
- **更简单的做法**（推荐）：不要动 delegate，直接对 toolbar 的 `View` 调
  `set_bounds(Rect { x: 0, y: 0, width: 窗口宽, height: 新高度 })`，再 `window.layout()`
  ——`switch_tab` 里压 hidden view bounds 那次已经验证过 `set_bounds` 有效
- 快捷键：`handle_shortcut`（`shell.rs` 里 `match ev.windows_key_code`）加
  `66 => { // Ctrl+Shift+B` 分支（B = 0x42 = 66），注意要先判 `shift`
- 隐藏时同时给页面加 class，让书签栏 DOM `display:none`（调 `run_toolbar_js`）
- **书签栏收起后，工具栏页面的 `html, body` 高度也要跟着变**（现在是写死 122px），
  否则页面底部会留白/溢出——用 `document.documentElement.style.height` 改
