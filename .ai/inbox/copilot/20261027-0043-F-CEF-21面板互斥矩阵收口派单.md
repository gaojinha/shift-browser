## 二、怎么改（要统一，不许再往 8 份清单上各补一行）

1. **单一事实源**：一张面板注册表，键=面板名，值=`(class 名, Rust extra 常量, setter)`。
   - Rust 侧：`const`+`static` 9 项：PW 260 / BM_POPUP 360 / DL 300 / MENU 340 / HIST 340 / SITE 150 / SETTINGS 320 / BM_MANAGE 380 / FIND_BAR 44（基准展开高 `TOOLBAR_HEIGHT_EXPANDED=122`，收起 88）。
   - JS 侧根类 8 项：`bmmanage-open / dl-open / find-open / hist-open / menu-open / pw-open / settings-open / site-open`。
2. **Rust**：抽 `clear_all_extras_except(keep: Panel)`，8 个 setter 的 `if open { … }` 段统一改调它（`apply_toolbar_height()` 保持调用）。
3. **JS**：抽 `removePanelClasses(except)`，注入段里由注册表常量生成清单（**JS 侧不能直接读 Rust 常量，靠 `cargo test --lib ts_export` 那套生成/防漂移机制钉住两侧一致**，沿用 F-CEF-07 的做法）。
4. 单测：断言「开任一面板时，除自己外全部 extra 为 0 / 全部根 class 不含」，8 面板 56 对全覆盖；Rust 侧断言 extra 归零，JS 侧断言清单长度与注册表一致。
