# 看了 Hallmark 之后，两个更适合你项目的备选

我帮你从 GitHub 翻了下一批，挑了两个值得装进来用的：

**1. Leonxlnx/taste-skill（~99k stars，同方向顶流）**
Hallmark 的 2.5 倍热，但关键区别：**v2.1 支持仪表盘/管理屏**。Hallmark 只做落地页，taste-skill 专门有 "quiet panels / aligned figures / colour spent on data" 的规则——对应你现在的标签栏、面板、设置页。还附一套 WAI-ARIA 组件状态机（button 8 states、dialog/tooltip 键盘导航）。安装：`npx skills add Leonxlnx/taste-skill --skill "design-taste-frontend"`

**2. Ferousco-dev/anti-slop-design（~48k stars）**
比 Hallmark 更模块化的反 slop 规则集，20 个独立模块，**第 17 模块"App Screen Rules"专管 onboarding / feed / settings / paywall 这些你天天做的界面**。Module 09 还有 ARIA  misuse 清单（shift-browser 里 `aria-expanded` 跨线程调用的那个雷刚好对得上）。

两个都是 Agent Skill 格式，装进 `.claude/skills/` 就行，不增加运行时依赖。你要不要装其中一个试试？
