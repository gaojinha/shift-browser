## ⚠️ 发现一个产品怪癖（未修，请拍板要不要立卡）

**username 为 NULL 的密码条目重复导入会插重复行**。根因：SQLite `UNIQUE(domain, username)` 中 NULL 互不相等，`ON CONFLICT(domain, username) DO UPDATE` 对 NULL username 永不命中 → 每次导入同一条 NULL-username 记录都走 INSERT。影响面：多端同步反复推送含"无用户名"的密码条目时，passwords 表持续膨胀（每条重复一行、密码值相同、仅 created_at 时间戳不同）。修法候选：冲突目标改 `COALESCE` 派生列 / 导入前按 domain 查 NULL-username 分支。本次测试里该分支用 `username='b'` 绕开（注释已标明怪癖），未把 bug 钉进断言。
