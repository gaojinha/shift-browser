## 4. 风险点（按严重度）

### 🔴 P0 — `passwords_ui.rs:86-104` 剪贴板密码全链路跨线程

**文件:行**：`src-tauri/src/engine/cef/passwords_ui.rs:86-104`
**触发路径**：用户点"复制密码"→ `handle_action("pwcop", id)` → `copy_password(id)` → `gtk::Clipboard::get` + `clip.set_text` + `timeout_add_local_once(30s, || { clip.wait_for_text + clip.clear })`
**后果**：
- `gdk_clipboard_get` 内部取 display 关联的 default main context。CEF UI 线程 ≠ GTK 主线程 → **glib panic**（"default main context already acquired by another thread"）或**静默失败**（剪贴板写入无效，30s 后自动清空不触发）。
- 回归未覆盖此路径（无"复制密码"操作项），所以 7 项全过不代表此处安全。
**修法**（给二狗）：
```rust
fn copy_password(id: i64) {
    // ... DB 查询 + zeroize 逻辑保持 ...
    let plain = ...;
    let digest = Sha256::digest(plain.as_bytes());
    let plain_owned = plain.clone(); // 或 to_string
    gtk_ui(move || {
        let clip = gtk::Clipboard::get(&gtk::gdk::SELECTION_CLIPBOARD);
        clip.set_text(&plain_owned);
        plain_owned.zeroize();
        log::info!("[cef] 密码 id={id} 已复制到剪贴板，{CLIPBOARD_CLEAR_SECS}s 后自动清空");
        gtk::glib::timeout_add_local_once(
            std::time::Duration::from_secs(CLIPBOARD_CLEAR_SECS),
            move || {
                let clip = gtk::Clipboard::get(&gtk::gdk::SELECTION_CLIPBOARD);
                let still_ours = clip
                    .wait_for_text()
                    .map(|t| Sha256::digest(t.as_bytes()) == digest)
                    .unwrap_or(false);
                if still_ours {
                    clip.clear();
                    log::info!("[cef] 剪贴板中的密码已自动清空");
                }
            },
        );
    });
}
```

### ⚠️ P2 — `shell.rs:587` (×3) `on_window_created` 内 timer 注册

**文件:行**：`src-tauri/src/engine/cef/shell.rs:587-593`
**触发路径**：CEF 窗口创建 → `on_window_created` 回调（CEF UI 线程）→ `timeout_add_local_once(800/2000/4000ms, ...)`
**后果**：timer 注册在 CEF UI 线程 glib context。当前 CEF 版本下实测能触发（回归全过），但属非预期用法。未来 CEF 升级改 glib 集成方式可能使 timer 永不触发 → 书签/标签栏初始推送丢失。
