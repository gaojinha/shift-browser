# F-CEF-24a CEF UI 线程投递辅助 · 交付回执

## 一、干了啥

新建 `src-tauri/src/engine/cef/cef_ui.rs`（250 行）+ `mod.rs` 一行注册，**禁改文件（shell/browser/toolbar/cef_cmd/bootstrap）零触碰，未翻 `multi_threaded_message_loop`**。交付项逐条对账：

1. **`UiExecutor` trait**（`Send + Sync`，可注入）：`on_ui_thread() -> bool` / `post(Box<dyn FnOnce() + Send>)` —— 与卡面签名一致。
2. **`CefUiExecutor` 默认实现**：`on_ui_thread` = `cef::currently_on(ThreadId::UI) == 1`；`post` 用 `cef::wrap_task!` 定义 `UiPostTask` + `cef::post_task(ThreadId::UI, Some(&mut task))`（用法参照 crate `message_router.rs:382-384`）。
3. **两个公开函数**：`cef_ui`（已在 UI 线程原地执行，否则 post）/ `cef_ui_call<R>`（原地执行返回；否则 mpsc 投递 + `recv()` 等结果）。内部各走一个私有核心 `cef_ui_with`/`cef_ui_call_with`（executor 参数可注入），公开入口固定默认实现——卡面签名不变，单测经核心注入 stub。
4. **单测 5 例**（卡面要求 ≥3，用进程内 `InlineExecutor`，不依赖真 CEF）：
   - 短路：`on_ui_thread()==true` → 原地执行、`post` 0 次；
   - 非 UI 线程：恰好 post 1 次、取走前不执行、取走后执行；
   - 回传：`cef_ui_call` 返回投递闭包的正确值（41+1=42）；
   - `cef_ui_call` 同样短路（post 0 次）；
   - 顺序：连续 post 两任务，FIFO 执行顺序不变。
5. **`mod.rs` 注册** `pub mod cef_ui;`（一行，二狗 08:27 边界提醒已收，`git diff mod.rs` 实查仅此一行）。

**设计要点**：
- `wrap_task!` 生成的 `Clone` 对每个字段调 `.clone()` 且 `execute(&self)` 只有共享引用 → 闭包容器定为 `type ClosureBox = Arc<Mutex<Option<Box<dyn FnOnce() + Send>>>>`（Arc 满足 Clone、`Mutex::take()` 保证恰好一次）；type alias 同时消掉 clippy `type_complexity`。
- **死锁铁律**已写进模块文档注释 + `cef_ui_call` 函数注释：`currently_on` 短路是正确性前提，CEF 回调链里调 `cef_ui_call` 不自短路 = post 给自己必死锁。
- `cef_ui_call` 的 `recv()` 错误路径（post 未入队，CEF 未初始化/已销毁）显式 `panic!` 带诊断信息——`f` 已移入投递闭包无法原地降级，该路径正常运行不会走到，属编程错误显式失败。
- `execute` 内锁毒化降级为跳过（项目口径：毒化恢复不裸 unwrap）。
- **交付期 `#![allow(dead_code)]`**（整模块暂无业务引用，24b/24c 才接线）——照 `groups_ui`/`downloads_ui`/`sessions_ui` 交付期口径，模块注释已注明**接线完成后删掉该行**。

**三处编译修复 + 两处消警（自列，均系首编暴露）**：
1. `wrap_task!` → `cef::wrap_task!`（`#[macro_export]` 宏跨 crate 必须全路径）；
2. 测试 2 处 E0373：局部 `AtomicBool` 改 `Arc`（'static 闭包要求）;
3. `wrap_task!` 展开的 Clone 调 `add_ref()`（`cef::rc::Rc` trait 方法）→ 加 `use cef::rc::Rc as _;`（cef crate 内部同款写法）；
4. 消警：6 条 dead_code → 交付期 scoped `#![allow]`；1 条 `type_complexity` → `ClosureBox` type alias。
