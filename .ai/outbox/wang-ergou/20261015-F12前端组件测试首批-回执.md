### ⚠️ 本次事故与止损（必须记一笔）
提交第二批时用了 `git add -A`，把 **atomcode 正在做的 F-22 在途文件**
（`src-tauri/src/newtab.rs`、`feed.rs`）一并卷进了我的提交 `88ab65f`——
等于替别人提交了半成品。

**止损**（代码未 push，本地改写历史）：
1. 先备份被误收的两个文件到 `/tmp/opencode/wip-backup/`；
2. `git reset --soft HEAD~1` 回退；
3. `git restore --staged` 把两个 Rust 文件退出暂存区（改动留工作树，还给 atomcode）；
4. 重新提交 `91dc733`，只含自己的 2 个测试文件；
5. `diff -q` 与备份逐个核对——**atomcode 的改动一字未丢**，现仍以未提交状态在工作树。

**根因**：多执行者（atomcode/copilot/二狗）**共用同一个 Git 工作树**，`git add -A` 不区分作者。
**规矩**：今后提交一律显式点名自己的文件（`git commit -- <paths>`），提交前看
`git status --short`、提交后看 `git show --stat HEAD`。
已记 `.learnings/2026-10-15-no-git-add-all-in-shared-worktree.md`。
