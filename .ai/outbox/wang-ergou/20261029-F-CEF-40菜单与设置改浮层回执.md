# F-CEF-40 主菜单改 GTK 原生 + 设置改独立标签页 回执

- 日期：2026-10-29
- 执行/自验：王二狗（自验，非独立第三方复核）
- 起因：高哥报「标签栏菜单后面有整个页面大的背景」「设置页不是弹窗，是下拉了个瀑布」

## 一、根因

CEF 里工具栏 view 与内容 view 上下分离，菜单/设置等面板靠 `set_panel_extra` 加高工具栏 view 实现：
- 加高必然把内容页往下推（瀑布）
- 面板背景铺满整块加高区，菜单只占右侧一列（大背景）
- 菜单 19 项超过 340px，底部被裁

不是 CSS 问题，是视图架构问题。

## 二、改法

**主菜单 → GTK 原生弹出菜单**
- `shell.rs` 新增 `popup_main_menu()`：`gtk::Menu` + 19 个 `MenuItem`，`popup_easy(0,0)` 弹在鼠标位置
- 菜单项回调 `cef_ui(move || handle_action(&act))` 投回 CEF UI 线程
- `menupanel|1` 只弹菜单，不再动工具栏高度；删除 `set_menu_panel`
- `toolbar.rs`：`#menupanel` CSS 隐藏；`setMenuPanel` 只发 `act`，不保留 `menu-open` 状态（否则隔次点击被 toggle 成关闭）

**设置 → 独立标签页**
- 新增 `resources/newtab/settings.html`：深色，搜索引擎/下载目录/广告拦截/GPC/保存
- `newtab.rs` 新增 `ensure_settings_html()`，随启动页一起生成
- `shell.rs` 新增 `settingspage` 动作、`open_settings_page()`、`eval_active_js()`
- `SHIFT_SET:` console 通道（只接受 `settings.html` 来源）；`send_settings`/`save_settings` 改为推活动标签页

## 三、踩坑（已记入代码注释）

1. **CEF 模式没有 Tauri `"main"` 窗口**：`create_main_window` 只给 WebKit 建，`app.get_window("main")` 永远 None。GTK 菜单不需要父窗口，直接 `run_on_main_thread` 弹。
2. **GTK 主线程 ≠ CEF UI 线程**：菜单项回调里直接调 `handle_action` 静默无效（`browser_view_create` 不执行），必须 `cef_ui` 投回。
3. `popup_at_pointer` 在异步主线程闭包里丢事件时间，菜单弹出即关；改 `popup_easy(0,0)`。

## 七、标签右键 + 书签文件夹下拉（2026-10-29 补）

高哥澄清：出问题的是**书签栏文件夹**（如「本地服务」）点开的下拉，不是标签右键；标签右键菜单也太矮。

**改动**

- 标签右键：`act('tabmenu|' + idx)` → `popup_tab_menu()` GTK 原生菜单，7 项（重新加载/复制/固定/静音/关闭/关其他/关右侧），不再困在 122px 工具栏。
- 书签文件夹下拉：`showFolderMenu` 只传 `folder.id + 点击项左下角坐标`，宿主查 DB（bookmarks + bookmark_folders）构建 GTK 菜单，子文件夹递归成子菜单；空文件夹显示禁用的「这个文件夹是空的」。
- 位置：`popup_at_rect(root, 窗口位置+点击项左下角, SouthWest/NorthWest)`，菜单左上角对齐点击项左下角；宽度 `set_size_request(320, -1)` 对齐 Chrome。
- 菜单项动作统一 `cef_ui(move || handle_action(...))` 投回 CEF UI 线程。

**真机验证**

| 项 | 结果 |
|---|---|
| 点「本地服务」 | 菜单 334×214，锚点日志 `win(320,126)+rel(898,122)`，落在点击项正下方左对齐 |
| 点菜单第一项 OpenRung | 页面导航到 `https://www.openrung.org/zh/#download`，日志 `[cef] 工具栏导航 -> ...` |
| 菜单宽度 | 320px，7 项完整 |
| 关窗 | 进程归零 |

**注意**：上一版「点击不能打开网站」的原因未完全定论——本轮在最新二进制上点击可正常导航；可能是旧安装版 + 菜单项回调未投 CEF UI 线程的组合。现版本已统一走 `cef_ui`。
