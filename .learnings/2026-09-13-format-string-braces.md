# format! 花括号速查(给自己,免得下次又考古两小时)
## 症状
newtab.rs 是 `format!` 整段 JS。JS 对象字面量 `{title,content}` / `{x,y}` 在 format! 里:
- 编译期:报 `error: invalid format string: python's numeric grouping ','`,指向具体行。
- 修法:把**演示/注释里的单花括号**写成 `{{}}`,整段只在 Rust format! 视角配平(Rust 版是 `{{`/`}}` 一对;键序冒号 `{#x}` 不知道,反正 format! 里只有 `{{`/`}}` 是转义对)。
## 已验证的"整段配平法"(一次对,不考古)
- 只要 `format!` 段落里,`{{` 和 `}}` **各出现偶数次**(含转义),单花括号剩 0 → 才是格式串合法→编译器直接给绿。
- 上次整段配平脚本:数 `{{`/`}}` 各自 `count`,不等→有裸花括号,往下找。
