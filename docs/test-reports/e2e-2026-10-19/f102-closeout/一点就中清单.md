## 五步清单

### 第 1 步 · 点「导入」图标（启动页侧栏）
- 所在界面：新标签页（`shift://newtab`）左侧图标栏
- 元素：button，`aria-label="从浏览器导入"`（无可见文字）
- **稳定 selector：`#importBtn`**
- `action/find` 实测（2026-10-19 17:16）：`found:1, role:button, tag:button, rect x15 y279 36×36, visible:true`

### 第 2 步 · 面板打开 + 切「书签」页签
- 所在界面：主窗口弹窗「从浏览器导入」（UiDialog，title=从浏览器导入）
- 面板容器：`[data-testid="import-module"]`
- 页签按钮：书签=`.import-tab`（第 1 个，role=tab，文本「书签」）；密码=第 2 个（文本「密码」）
- 注：面板默认页签即「书签」，此步通常可跳过

### 第 3 步 · 看书签预览（按文件夹分组）
- 容器：`[data-testid="bm-preview"]`；分组行：`.preview-group`，每组有 `.preview-folder`（文件夹名+条数）
- 预期：Chrome/Brave 摘要两行 + 分组树；无任何明文（书签只有标题+URL）

### 第 4 步 · 点「导入书签」
- 元素：button，文本「导入书签」（导入中变「导入中…」且 disabled）
- selector：`.import-section .import-run`（书签页签下的那个）
- 回执区：`[data-testid="bm-result"]` → 显示「写入 N 条 / 合并去重 / 拒收不安全链接」

### 第 5 步 · 切「密码」页签 → 点「导入密码」
- 先点第 2 个 `.import-tab`（文本「密码」）
- 预览容器：`[data-testid="pw-preview"]`，每行 `.preview-name`=域名 / `.preview-sub`=用户名 / `.preview-pass`=**`••••`（不得出现明文）**
- 导入按钮：`.import-section .import-run`（密码页签下，文本「导入密码」）
- 回执区：`[data-testid="pw-result"]` → 「写入 N 条 / **已存在跳过 N 条** / 空密码跳过 / 失败」

### 第 6 步（F-98 现场闭环）· 再点一次「导入密码」
- 同一按钮再点一次，回执应显示「写入 0 条」+「已存在跳过 N 条」= insert-only 跳过而非覆盖
- 数据肉眼确认：密码管理器（PasswordsDialog）、书签栏/书签管理器（BookmarksDialog）

## 卡点（如实记）

1. **写闸门未开**：`api_agent_actions=false`，`action/click` 探针返回 `E_PERM`（"需在设置里开启「允许 API 页面交互」"）。三道闸门（api_agent_actions / api_readonly / api_allow_eval）按红线未动，只能高哥本人在 `设置 → 高级 → 开放 API（高级）` 开。
2. 因此第 2~6 步的 selector 来自源码而非 `action/find` 实抓（面板不点开就不存在）；第 1 步 `#importBtn` 为实抓。
3. 高哥回机后：**若只点 5 下**照上面步骤走；**若开了 api_agent_actions**，本清单 selector 可直接喂 `action/click` 全自动走完，到时喊我一声即可。
