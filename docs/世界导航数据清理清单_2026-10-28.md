## 四、跨类重复（43 组，不删数据，设计层合并）

同一 URL 出现在多个分类，本身不算错——一个站可以属于多个类。原页面把它们当成独立卡片重复展示，新设计这样处理：

- **归类**：按 JSON 里第一次出现的分类作为「主分类」。
- **搜索**：一个站只出一条结果，行尾标「+N 类」（如「知乎 · 学习/社交」）。
- **计数**：分类行显示该类条目数，不因跨类去重而减少。
- **收藏**：按 URL 判重，同一个站只能收藏一次。

主要重复簇：

| 簇 | 例子 |
|---|---|
| 新闻 / 财经 | 路透社、NYT、WSJ、FT、Bloomberg、Economist、AP |
| 旅游 / 交通 | 携程、去哪儿、飞猪、12306、高德 |
| 美食 / 生活 / 服务 | 美团、饿了么、大众点评、下厨房、丁香医生 |
| 二手 / 赚钱 / 兼职 | 闲鱼、转转、猪八戒、Upwork、Fiverr |
| 工作 / 工具 | ProcessOn |
| 其他 | Medium×3、Airbnb×3、Booking×3 |

另：`favorites` 不是内容分类，是内置的 12 个默认收藏（Google、Bing、邮箱等），新界面单独放在「收藏」区，不进 32 类索引。

## 附：复测命令

```bash
# 全量 DNS 解析
python3 - <<'PY'
import json, urllib.parse, subprocess, concurrent.futures
d=json.load(open('src-tauri/resources/worldnav.json'))
hosts=sorted({urllib.parse.urlparse(s['u']).netloc.lower() for c in d for s in c['sites']})
def r(h):
    try:
        o=subprocess.run(['dig','+short','+time=2','+tries=1',h,'A','@223.5.5.5'],capture_output=True,text=True,timeout=5).stdout
        return h,bool([x for x in o.strip().splitlines() if x and not x.endswith('.')])
    except Exception: return h,False
with concurrent.futures.ThreadPoolExecutor(max_workers=40) as ex:
    for h,ok in ex.map(r,hosts):
        if not ok: print('DNS FAIL',h)
PY
```
