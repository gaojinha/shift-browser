## 二、新增命令

**读取（Read）**
- `open_and_read`：一次完成「开标签→等加载→读取」（`mode`/`selector`/`close`/`reuse`/`ua`）
- `read_status`：标签状态与元信息（就绪态/hints）
- `extract`：按 selector + fields 白名单结构化提取
- `reader/extract`：给 URL 出净化正文
- `translate`：文本翻译
- `content/snapshot`：活动标签语义快照
- `audit/reads`：AI 操作审计查询
- `audit/egress`：网络外发端点清单
- `action/wait_for`：等待元素出现/消失/加载完成

**写入与交互（Write）**
- `tabs/close_ai`：只回收 AI 标签（不碰用户标签）
- `action/dismiss`：保守关闭常见弹窗
- `action/scroll` / `action/click` / `action/fill` / `action/back` / `action/hover` / `action/key`

## 三、读取增强（read_page）

`tab_id`（多标签）· `lazy`（滚到底触发懒加载）· `expand`（展开 details）· `shadow`（穿透开放 shadow root）· `iframe`（同源并入/跨源提示）· `meta` · `hints`（canvas/登录/验证码）· `empty` · `ts` · 图片真实地址 · 表格 `merged` 标记 · F4 原生 DOM 引用防 monkey-patch。

## 四、三个开关（都在设置里，可从开放 API 设置页开）

| 键 | 默认 | 作用 |
|---|---|---|
| `api_readonly` | false | 只读模式：拒一切写命令；**`open_and_read` 等读命令放行**（能看不能动） |
| `api_agent_actions` | **false** | 页面交互总开关（`action/*` 全系列） |
| `api_allowed_ips` | 空 | IP 白名单；**内网/私有地址默认拒绝**，白名单内放行 |

## 五、安全与隐私（本次加固）

- **SSRF 纵深**：入口校验 + 最终 URL 复核 + GTK 逐跳导航拦截（AI 标签专属，用户标签不受限）
- **内容隔离**：读取响应带 `content_type:"page"`（prompt-injection 隔离依据）
- **审计**：`ai_audit` 表记所有 API 操作（命令/url/结果码，**不记内容**）
- **标签治理**：`origin` 标记；AI 标签**不写浏览历史**、上限 10、可批量回收、后台打开不抢焦点
- **截图治理**：目录只保留最近 100 张
- **交互安全**：固定脚本 + 独立开关 + 交互预检 + 每次现查 DOM；`fill` 只落字符串
