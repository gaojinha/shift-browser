3. **前端测试 3 → 69 用例**（7 文件，1,158 行），stores 关键路径（tabs/ai/settings）与 markdown XSS、invoke 契约已有护栏；Rust 测试 187 → **207 全过**；
4. **错误类型化七码体系落地**：44 个命令已迁 `CommandResult<T>`，前端 `invokeOk/errText` 契约就位；
5. **shift:// 协议 CSP 在 release 构建启用 per-response nonce**（[shift.rs:39-61](file:///home/gao/shift-browser-tauri/src-tauri/src/proto/shift.rs#L39)），内联脚本 XSS 面在生产构建收窄。

但本轮新基线也暴露出 **一个 v2 未发现的真实护栏缺口**和若干"治理后反弹/长尾未竟"问题：
