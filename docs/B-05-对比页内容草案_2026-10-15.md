## 二、三大差异化叙事（页面上半部文案骨架）

1. **AI 原生，不是弹窗**——"把浏览器当作 AI 的手和眼"：MCP 开放 API 让本机 AI 直接读页面、管标签、存书签；默认只读、敏感动作显式开启、IP 白名单——能力开放与权限收敛并行。
2. **隐私不靠承诺靠结构**——历史默认不记录；AI Key/密码读接口只给掩码；设置键全白名单，裸字符串进不了读写层；GPC 法规先行默认开。
3. **轻，是因为不捆绑**——36 MB：内核交给系统 WebKitGTK，系统补丁即浏览器补丁；代价是渲染兼容性跟随系统版本（如实披露，见"诚实的局限"）。

## 三、"诚实的局限"（对比页可信度区——Brave Reviewer's Guide 的核心手法）

主动列出，不藏：
- 内核随系统：WebKitGTK 老系统上兼容性受限（Cloudflare 类站点兼容问题已在诊断线跟踪）；
- 多进程隔离未达 Chrome 形态（维度 P2 长期路线）；
- 生态：无 Chrome 扩展商店兼容层（自研用户脚本路线）；
- 无移动端 / 无同步（同步已立案待战略拍板）。
