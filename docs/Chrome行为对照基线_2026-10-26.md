## 二、页面右键菜单

Chrome 按上下文给不同菜单，我们目前只做「空白处」：

| 上下文 | Chrome 菜单项 | 我们的现状 |
|---|---|---|
| 空白 | 后退 / 前进 / 重新加载 / 另存为 / 打印 / 翻译成中文 / 查看网页源代码 / 检查 | ✅ 后退/前进/重新加载/复制/全选/查看源代码（`9f1590c`）；打印/翻译/检查待补 |
| 链接 | 在新标签页打开 / 在新窗口打开 / 无痕打开 / 复制链接地址 / 另存为 / 检查 | ⏳ 待补（需 `ContextMenuParams.link_url`） |
| 图片 | 在新标签页打开图片 / 图片另存为 / 复制图片 / 复制图片地址 / 检查 | ⏳ 待补（需 `ContextMenuParams.src_url`） |
| 选中文本 | 复制 / 搜索 / 打印 / 检查 | ⏳ 待补（需 `selection_text`） |

**实现注意**：CEF Alloy 运行时不调用 `GetContextMenuHandler`（2026-10-26 实测），
所以菜单是内容页注入自绘的（`CONTEXT_MENU_JS`）。要按上下文分菜单，
得让注入脚本读 `window.getSelection()` / `event.target` 自己判断，
或改用 `CefMessageRouter` 把 `ContextMenuParams` 送到页面。

**安全铁律**：内容页 console 只放行 `ctx*` 白名单（见 `ShellContentDisplay::on_console_message`），
页面脚本伪造 `SHIFT_ACT:` 不能触发标签/窗口/书签/密码等敏感动作。

## 四、地址栏

Chrome 行为：
- 输入即给建议：**历史 > 书签 > 搜索建议**，按 URL 去重；
- 键盘 ↑↓ 选择、Enter 打开、Esc 关闭；
- 右侧有书签星标（点击收藏/取消）、站点信息（锁/证书）。

我们的现状（`12a8989`）：
- ✅ 历史 + 书签各 8 条，URL 去重（书签优先），LIKE 通配符转义；
- ✅ ↑↓/Enter/Esc/点外收起；
- ✅ 星标收藏/取消 + 地址变化自动刷新；
- ⏳ **搜索建议**（不是搜索历史，是输入时向搜索引擎要联想词）未做——涉及外部请求与隐私，单独立项；
- ⏳ 站点信息（安全锁/证书/权限）→ F-CEF-19。

## 五、缩放

Chrome 档位：**90 / 100 / 110 / 125 / 150 / 175 / 200 %**，Ctrl+`+`/`-` 逐档，Ctrl+`0` 回 100%；
按站点记忆（同一站点下次打开保持）。

CEF 实现要点：
- `BrowserHost::set_zoom_level(f64)`，zoom level 0 = 100%，每 +1 = 120%；
- 档位换算：`ln(scale)/ln(1.2)`；
- 现状：F-CEF-18 在做（只做当前标签，按站点记忆放 P2）。

## 六、查找栏

Chrome 行为：Ctrl+F 顶部弹查找栏，输入即时高亮，显示 `当前/总数`，
Enter 下一个、Shift+Enter 上一个、Esc 关闭并清除高亮。

CEF 实现要点：
- `BrowserHost::find(identifier, text, forward, match_case, find_next)`；
- `FindHandler::on_find_result(identifier, count, rect, active_match_ordinal, final_update)`；
- **计数必须是 CEF 回调真值**，不许页面 JS 自己数 DOM 充数（验收会查）。

## 七、下载

Chrome 行为：下载开始后地址栏右侧出现下载箭头，点开是下载气泡/面板；
面板含进度、暂停/继续、取消、在文件夹中显示、重新下载。

我们的现状（`45d5227`）：
- ✅ attachment 自动转下载（`on_resource_response`）；
- ✅ 用户下载目录 / 同名去重 / downloads 表记账 / 进度 / 终态；
- ✅ 工具栏下载面板：进度条、打开目录、重下、删记录；
- ⏳ 暂停/继续、在文件夹中显示（单文件定位）、下载气泡（当前是面板）；
- ⏳ 302 二次下载风险（用原 URL `start_download`，大文件可能多一次请求）——已在 F-CEF-14 交接单记录，未验。

## 九、验收方法（CDP）

仓库内工具（不再依赖 /tmp）：
- `scripts/cef-coordinator/cdp-eval-any.py <port> <url子串> <js>`：对指定 target 求值；
- `scripts/cef-coordinator/cdp-rightclick.py <port> <url子串> [x] [y]`：发右键；
- `scripts/cef-coordinator/cef-eval.py`：CF/指纹采样用（优先 http target）。

通用检查点：
1. 菜单：`.menu-item` 数量、`.disabled` 数量、面板互斥 class（`menu-open`/`dl-open`/`pw-open`/`bookmarks-hidden`）；
2. 右键：`#__shift_ctxmenu` 是否存在、项文本、点击后 `navigation.type`/`getSelection()`；
3. 建议：`#omni.open`、`.omni-item` 数量、`.active` 索引；
4. 星标：`#starbtn.on` + 数据库 `bookmarks` 表逐条对账；
5. 下载：文件大小、原页 URL、`.crdownload`、`downloads` 表 `completed`。
