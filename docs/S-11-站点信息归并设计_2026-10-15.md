## 一、现状盘点

### 1.1 散件定位（file:line）

S-11 的"站点信息"指**浏览器 UI 中跟当前站点有关的安全/权限/隐私信息的展示入口**，包括：证书警告、权限请求、护盾状态。三件散件现状如下：

| 散件 | 文件 | 行数 | 触发方式 | 展示内容 |
|---|---|---|---|---|
| 证书警告 | `src/components/CertWarning.vue` | 267 | `tls-error` 事件（`App.vue` 监听） | host/subject/issuer/notAfter/fingerprint + 原因列表；"继续前往"走 `accept_cert_exception` |
| 权限请求 | `src/components/PermissionPrompt.vue` | 191 | `permission-request` 事件（`App.vue` 监听） | host + 权限类型（kindZh）；允许/拒绝 + "记住"复选框；走 `respond_permission` |
| 护盾面板 | `src/components/ShieldPanel.vue` | 413 | 地址栏盾按钮（`AddressBar.vue:310-327`，`defineAsyncComponent` 懒加载） | 站点域名 + 防护状态（UP/降盾）；本页计数（`get_privacy_stats`）；降盾/恢复切换（白名单） |

### 1.2 三件散件之间的关系

```
站点安全/隐私信息
├── 证书异常  →  CertWarning（模态，出现时 hide webview，压住所有浮层）
├── 权限请求  →  PermissionPrompt（模态，出现时 hide webview）
└── 防护状态  →  ShieldPanel（地址栏弹层，非模态，懒加载）
                  ↑ 地址栏盾按钮在 http/https 页显示（AddressBar.vue:58）
```

**当前的问题**（I2 设计稿标注的"信息架构收敛"）：
- 三件信息**各自独立触发**，用户要切换视角（看盾 → 看权限历史 → 看证书状态）没有统一入口
- 证书警告是"异常才弹"，**无证书/无警告时没有主动入口可查站点证书**
- 权限请求是"弹了才知道"，**无权限列表入口可查当前站点的已授权权限**
- 护盾面板只有护盾状态 + 计数，**没有把"该站点所有安全信息"收拢**

### 1.3 涉及的 Rust 侧能力（只读，不新增）

| 能力 | Rust 位置（参考） | 说明 |
|---|---|---|
| `get_privacy_stats` | `src-tauri/src/`（shield 相关） | 返回全局统计（重启归零） |
| `is_site_shield_off` / `toggle_site_shield` | `src-tauri/src/` | 站点白名单读写 |
| `accept_cert_exception` | `src-tauri/src/` | 证书例外放行 |
| `respond_permission` | `src-tauri/src/` | 权限应答 |

> Rust 侧目前**无站点级权限列表查询接口**（即"该站已授权了哪些权限"），这是归并方案的已知缺口。

## 二、归并方案 B（信息架构收敛，不加新功能）

### 2.1 目标结构：站点信息中心（SiteInfoPanel）

**入口**：地址栏盾按钮（已有，`AddressBar.vue:310`）——点击行为从"切盾状态"升级为"**打开站点信息中心**"。

**面板内容（四区）**：

```
┌─ 站点信息中心（SiteInfoPanel）────────────────────────┐
│                                                        │
│  ① 连接安全性（证书区）                                  │
│     正常：绿点 + "连接安全（HTTPS）" + 查看证书（展开）    │
│     异常：红点 + 原因摘要 + "继续前往"（= 现有 CertWarning 动作）│
│                                                        │
│  ② 权限状态（权限区）                                    │
│     当前站点已授权权限列表（只读）                         │
│     待应答权限：允许/拒绝按钮（= 现有 PermissionPrompt 动作）│
│                                                        │
│  ③ 护盾状态（盾区）= 现有 ShieldPanel 内容原样搬入         │
│     防护状态 / 本页计数 / 降盾切换                         │
│                                                        │
│  ④ 站点级设置（设置区）（占位，待 C-8/C-9 立案）           │
│     （无内容时显示"该站点暂无可配置项"）                    │
└────────────────────────────────────────────────────────┘
```

### 2.2 各原位置改造映射（保留链接，不删原始内容）

| 原组件 | 改造方式 | 原文件保留？ |
|---|---|---|
| `CertWarning.vue`（267 行） | **不删**。"继续前往"动作提取到共享函数；证书异常时**仍在原模态弹出**（安全警告模态不可降级为面板内区域），SiteInfoPanel 的"连接安全性"区只读展示证书摘要 + 触发 CertWarning 的按钮 | ✅ 保留 `src/components/CertWarning.vue`，加注释指向 SiteInfoPanel |
| `PermissionPrompt.vue`（191 行） | **不删**。权限请求模态弹窗逻辑不变（安全事件必须模态打断，不可降级为面板），SiteInfoPanel 权限区只读展示已授权列表 + "待应答权限"入口（点击触发现有模态） | ✅ 保留 `src/components/PermissionPrompt.vue`，加注释 |
| `ShieldPanel.vue`（413 行） | **降级为子组件**。SiteInfoPanel 导入 ShieldPanel 作为"盾区"内容，原文件保留；若单独打开盾面板的旧入口（地址栏盾按钮）行为改为打开 SiteInfoPanel，则 ShieldPanel 独立展示的场景消失，可后续评估是否移除（本次不动） | ✅ 保留，加注释 |
| `AddressBar.vue` 盾按钮 | 点击行为改：`toggleShieldPanel()` → `toggleSiteInfoPanel()`；`defineAsyncComponent` 指向 `SiteInfoPanel.vue` | 改 `AddressBar.vue`（产品代码，本稿只给方案） |

### 2.4 Rust 侧缺口（待补，不在本稿实施范围内）

| 缺口 | 说明 | 优先级 |
|---|---|---|
| `get_site_permissions(host)` | 查该站点已授权权限列表（settings 表或内存），SiteInfoPanel 权限区需要 | 中 |
| `get_cert_status(url)` | 主动查证书状态（不靠 tls-error 事件触发），"连接安全性"区无异常时显示详情 | 低 |
| `per_site_settings` | 站点级设置（屏蔽/白名单/默认盾状态），C-8/C-9 立案后填 | 中 |

> 三个缺口都不阻塞 SiteInfoPanel 基础版（证书区可只读现有 `tls-error` payload，权限区可显示"加载中"占位）。
