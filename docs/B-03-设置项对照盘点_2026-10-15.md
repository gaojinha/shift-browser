## 二、Brave 设置域 vs 我方对照

| Brave 设置域（pak 原文命中） | Brave 内容（公开结构⚡） | 我方现状 | 缺口判定 |
|---|---|---|---|
| Get started | 默认浏览器 / 导入 | ❌ 无导入、默认浏览器设置项 | 默认浏览器有 Rust 探测（default_browser.rs）但未入设置 UI；导入功能缺——低价值缓 |
| Appearance | 主题 / 缩放 / 主页按钮 / 字体 / 标签栏位置 | ✅ theme / theme_color / show_bookmarks_bar / vertical_tabs / font_size | 基本覆盖；缺页面级缩放设置（与 B-01 缩放缺口同源） |

| On startup | 启动行为 | ✅ homepage（newtab/URL） | 覆盖 |
| Shields（全局默认） | 广告拦截 / 块爬虫 / Fingerprinting 档位 | ✅ adblock_enabled(+keywords) / privacy_shield_level(off/standard/strict) / privacy_whitelist / gpc_header | **核心域已覆盖**；缺 Brave 的"块社交/爬虫"细分档（缓） |

| Autofill and passwords | 密码管理 / 支付卡 / 地址 | ✅ 密码库（vault_idle_lock_minutes + master_key 体系） | 覆盖（无支付卡/地址簿——缓） |

| Languages | 界面语言 / 翻译 | ✅ translate_engine/target；界面语言 i18n 进行中（R4-5） | 部分覆盖；缺"界面语言"设置项（等 i18n 全量后补） |

| Leo AI | AI 助手设置 | ✅ AI 组 9 键（provider/model/base_url/key 掩码/超时） | 覆盖且更开放（自定义 provider） |

| 企业策略 Group Policy | Managed by organization | ❌ 无 | 维度十二已判：长期路线，不适用 |

## 三、缺口分级（结论）

- **低风险可补（候选小包）**：① 下载目录设置项；② 一键重置设置（Reset settings 对齐）；③ 默认浏览器设置入 UI（后端已有 default_browser.rs）。
- **依赖其他线**：界面语言设置项（等 R4-5 i18n 全量）；页面级缩放（B-01 同源缺口）。
- **定位差异非缺项**：指纹方向（补齐 vs 防护）、Web3、扩展形态、企业策略。
- **战略立案不排期**：同步（维度十三）。
- **建议不做**：Cookie 策略域（WebKit 无等价拦截面，做了易出虚假安全感）、过滤器订阅（自研 userscripts 路线已覆盖场景，重复建设）。

## 四、给拍板人
1. 设置体系核心域（外观/搜索/启动/Shields/隐私/AI/性能/翻译）**已全覆盖**，53 键白名单+掩码+内部键三层防护是我方强项（Brave 无此读取侧防线设计）；
2. 值得补的只有 3 个小项（下载目录 / 重置 / 默认浏览器 UI 化），均可作后续小包；
3. "本地历史保留期限"（维度十二点名的检查项）**我们已有且更隐私优先**（record_history 默认关 + auto_clear_history_days）。
