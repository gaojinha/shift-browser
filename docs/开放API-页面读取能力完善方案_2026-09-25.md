# 开放 API · 页面读取能力完善方案（完整版）

> 状态：**定稿待拍板**（2026-09-25，三次修订）
> 定位：浏览器对 AI 的价值 = **替人看网页**。本方案围绕「读得到、读得全、读得快、读得稳、不把浏览器搞乱」，
> 以**问题全景驱动**设计开放 API 的页面读取能力。凡页面读取会碰到的问题，一律前置规划，不允许"遇到再说"。
> 修订记录：v1 能力分层 → v2 问题全景（A–L 十二类）→ 补 M 类页面形式适应性 → 补 N 类隐私保护 →
> 补 O 类安全加固 → 本次补 **P 类权限体系**（三层权限模型 / 只读放行语义 / 域名控制 / 权限审计 / 页面权限策略）。
> 架构红利（R1 拆分已就绪）：新增命令只需 ① `api/handlers/mod.rs` HANDLERS 表登记；② `capabilities/registry.rs`
> 登记风险等级（Read/Write）。之后只读闸门、MCP 暴露、防漂移测试自动生效，MCP bin（`bin/mcp_server.rs`）零改动。
> 范围外（后续可选，不在本方案）：数据写操作（书签/会话/设置增删改）——浏览器定位是「看」，数据管理优先级低，
> 等读取能力到位后再评估；密码库读写、证书管理、eval、tool_call 明确不补（底线）。

### 1.2 已处理问题（`page_read.js` 243 行核实，2026-09-25）

✅ 可见性过滤（display:none / visibility:hidden）· 非 http(s) URL 脱敏（data:/blob: 只留前缀+长度）·

### 1.3 核心缺口（按使用场景）

1. **不能「给个 URL 就帮你看」**——open_url + 等加载 + read_page 三步，且无等待/轮询手段；
2. **懒加载页面读不全**——滚动加载的页面一次只能读首屏；
3. **截图只有可见区域**——长页面/元素截图做不到；
4. **多标签读不了、iframe/shadow DOM 读不到**；
5. **无状态感知**——加载中/完/错，AI 只能盲等或 sleep 猜；
6. **无交互手段**——登录墙、加载更多、Cookie 弹窗挡路，读不到完整内容；
7. **AI 开标签会堆积**——无来源标记、无上限、无回收，会把浏览器搞乱。

## 2. 设计原则

| 原则 | 决策 |
|---|---|
| **原子化** | 一个命令完成「打开 → 等待 → 读取 → 可选关闭」闭环，AI 一句话"看"一个页面 |
| **固定脚本，非任意 JS** | 采集/交互脚本编译期嵌入，调用者只能选「动作 + 参数」，不能注入代码 |
| **读取优先** | 交互只服务于「读到内容」；交互失败有明确错误码，不静默 |
| **问题前置** | 已知问题一律在 §3 全景登记并给出应对 |
| **不把浏览器搞乱** | AI 标签可标识、有上限、可回收、后台打开不抢焦点、不污染会话快照、读取有审计 |
| **读活 DOM，不重抓 HTTP** | SPA 必须读已渲染的 webview DOM |
| **风险分级走注册表** | 写命令标 `Risk::Write`，自动受 `api_readonly` 闸门约束 |

## 3. 页面读取问题全景（16 大类）

每项：**问题 → 应对 → 落点命令**。✅ = 现状已处理。A–L 按问题维度，M 按页面形式，N 按隐私，O 按安全，P 按权限（正交补充）。

### A. 加载与等待

| # | 问题 | 应对 | 落点 |
|---|---|---|---|
| A1 | 页面加载慢 / 超时 | `wait_for` 条件 + 统一超时，超时返回**部分内容 + partial:true** | open_and_read |
| A2 | SPA 内容就绪：`load` 事件 ≠ 内容渲染完 | `wait_for` 五条件：`load` / `selector:xxx` / `selector_gone:xxx`（骨架屏消失）/ `stable:ms`（两次快照一致）/ `ms:3000` | open_and_read |
| A3 | 白屏 / 骨架屏 | `wait_for:selector_gone` 或 `stable` | open_and_read |
| A4 | 无限加载 / 实时刷新页（行情、聊天） | 读当前快照；超时返回已加载内容 + partial:true | open_and_read |
| A5 | 重定向（301/302/JS 跳转） | 返回 **final_url**（`location.href` 即最终 URL） | open_and_read / read_status |
| A6 | 证书错误页 | 识别证书错误（复用 `tls.rs`），返回 `error_type:cert_error` | open_and_read / read_status |
| A7 | 404 / 500 错误页 | HTTP 状态感知，返回 `error_type:http_error` | read_status / open_and_read |
| A8 | 等待条件永不满足 | 超时 → 干净错误 + 已加载内容（partial:true）+ 重试建议 | open_and_read |
| A9 | 断网 / 弱网 | 加载失败返回 `error_type:network_error`（与超时区分） | open_and_read / read_status |

### M. 页面形式适应性（按页面类型逐类适配）

不同网站/页面的形式差异巨大，逐类分析适配策略。✅ = 已有机制覆盖；本类新增的机制在落点标注「新增」。

| 页面形式 | 特征 | 适配策略 | 落点 |
|---|---|---|---|
| 静态 HTML | `load` 即就绪 | `wait_for:load` 即可 | ✅ |
| SSR 服务端渲染 | 首屏有内容 | `wait_for:load` 即可 | ✅ |
| SPA 客户端渲染 | `load` ≠ 内容就绪 | `wait_for:selector/stable` | ✅ A2 |
| 混合水合（SSR+客户端） | 水合期闪烁/重排 | `wait_for:stable`（两次快照一致） | ✅ A2 |
| Web Components | shadow DOM | `shadow:true` 尽力穿透 | ✅ B5 |
| Canvas/WebGL（图表/游戏/图形编辑器） | 读不到文本 | hints 提示截图 | ✅ B6 |

### N. 隐私保护（读取行为的隐私面）

本项目本身有完整隐私防护体系（广告拦截 / 指纹防护 / GPC / 跟踪防护 / 隐私审计 egress / netmon），
本类分析 **AI 读取行为与隐私防护的关系**。✅ = 已有机制。

| # | 问题 | 应对 | 落点 |
|---|---|---|---|
| N1 | AI 读取的页面写入浏览历史，**污染用户历史**（AI 读 100 页用户历史多 100 条） | **AI 标签（`origin:"ai"`）的页面访问不写入 history 表**；用户历史保持干净，AI 行为由 `audit/reads` 单独记录——可追溯性不丢，历史不脏 | 全局（history 写入逻辑按 origin 跳过） |
| N2 | AI 读取是否应用隐私保护（广告拦截/指纹防护/GPC/跟踪防护） | **继承用户隐私设置**：AI 打开的标签与用户浏览同一隐私策略（默认全开）——页面更干净、读取更快、指纹不被采集；**不因是 AI 就关防护** | 全局（标签创建继承隐私上下文） |
| N3 | AI 网络活动对用户不可见 | **egress audit 覆盖 AI 标签**：AI 打开页面发出的网络请求计入隐私审计，用户可查"AI 访问了什么" | audit/egress |
| N4 | AI 读取敏感页面（银行/支付/邮箱/医疗） | **敏感域名提示**：检测高敏感域名（内置白名单）→ hints"敏感页面，确认读取"（**不强制拦截**——信任面内，但让调用方知情） | hints 扩展 |
| N5 | 审计记录泄露读取内容 | 审计只记 url + 命令 + 结果码，**不记内容/表单值**（K5 重申） | audit/reads |
| N6 | 读取脚本采集多余数据 | 固定脚本**最小采集**：只读请求的 mode 内容，不采集 Cookie / localStorage / 其他标签页数据 ✅（page_read.js 已实现，新脚本同口径） | page_read.js / 新脚本 |
| N7 | API 日志泄露读取内容 | 日志只记命令名 + 计数 + 错误类型，不记内容 ✅ | 全局 |
| N8 | 用户对 AI 行为不知情 | **用户透明**：AI 开标签可见（后台化但不隐藏）、审计可查（audit/reads）、交互发生在可见标签（K2 重申） | 全局 |

> **新增机制汇总**（N 类）：① AI 标签不写浏览历史（origin 判断跳过 history 写入）；② AI 标签继承用户隐私设置；
> ③ egress audit 覆盖 AI 标签（开放 `audit/egress` 命令）；④ 敏感域名 hints（内置白名单）。

### O. 安全加固（整体安全纵深）

F 类是读取内容安全（SSRF/脱敏/monkey-patch），本类覆盖**全链路安全纵深**——传输鉴权、URL 网络、
内容、交互、数据、资源、调用方、审计八层。✅ = 已有机制。

| # | 问题 | 应对 | 落点 |
|---|---|---|---|
| O1 | **重定向绕过 SSRF**：open_and_read 跟随跳转，重定向到内网 | **重定向每跳校验**：跟随重定向时每跳重新执行 URL 白名单 + SSRF 校验；跳转超限报 redirect_loop（M 类） | open_and_read |
| O2 | 截图文件堆积占磁盘（AI 大量截图） | **截图目录治理**：screenshots 目录按数量/时间自动清理（保留最近 N 张，默认 100）；`close:true` 时截图随标签清理（可选） | screenshot / 全局 |
| O3 | 审计日志仅内存，重启丢失 | **审计持久化**：audit 写入 db 表（audit_log），可持久可查询；audit/reads 从 db 读 | audit/reads |
| O4 | **页面内容 prompt injection**：恶意页面内容诱导 AI 执行危险动作 | **内容隔离标记**：读取响应带 `content_type:"page"` 标记 + 文档提示 AI 调用方将页面内容视为**数据而非指令**；API 层不做内容善恶判断（见 O7） | 响应骨架 / 文档 |
| O5 | 恶意页面诱导 AI 点击危险操作（下载/删除/转账） | 交互预检（I2）+ 高风险动作文档提示（I12）+ 独立开关 api_agent_actions（默认关，三层兜底） | action/* |
| O6 | 端口扫描（AI 被诱导读内网端口） | 内网 URL 默认拒绝（M 类）+ 重定向每跳校验（O1） | open_and_read |
| O7 | 内容投毒（页面本身恶意/钓鱼） | **API 不判断内容善恶**——浏览器是"看"的工具不是"审"的工具；文档明示 AI 调用方对内容自行判断 | 文档 |
| O8 | 审计完整性 | audit/reads 记录**所有** AI 操作（读/交互/开标签），**不可关闭**（安全底线） | audit/reads |
| O9 | token / 凭据泄露 | ✅ 已有：token 文件 0600 / 常量时间比较 / 轮换热生效 / LoginGuard 指数退避 / 一次性门票 / IP 白名单（CIDR+IPv4-mapped 归一化） | 已有 |
| O10 | 新增依赖风险 | 本方案**零新增第三方依赖**（全部复用 db/reader/translate/audit/gpc/tls 现有模块）；固定脚本编译期嵌入 | 全局 |

> **新增机制汇总**（O 类）：① 重定向每跳校验（SSRF 强化）；② 截图目录治理（保留最近 N 张）；③ 审计持久化（db 表）；
> ④ 内容隔离标记 `content_type:"page"`；⑤ 文档明示：API 不判断内容善恶、高风险交互提示、prompt injection 提示。

### P. 权限体系（API 调用方权限 + 页面权限）

现有 `perms.rs` 管的是"网页向浏览器请求权限"（摄像头/通知等），本类管的是 **"AI 调用方经 API 操作浏览器的权限"**——两个维度，互不混淆。

| # | 问题 | 应对 | 落点 |
|---|---|---|---|
| P1 | 权限粒度：Read/Write 两级一刀切 | **三层权限模型**：Read（读取）/ Write（导航·清理·开标签）/ Interactive（交互动作）——写类受 `api_readonly` 闸门，交互类受 `api_agent_actions` 独立开关（默认关） | 全局（capabilities/registry.rs） |
| P2 | **只读模式下 open_and_read 被拒**——语义是读、动作却是开标签 | **open_and_read 只读放行**：只读模式允许 open_and_read（"能看不能动"），拒绝 action/* 与 tabs/close_ai——符合"浏览器是看页面"的定位 | api.rs 闸门 |
| P3 | 域名级控制：AI 能读任何 URL？ | **域名 denylist（可选）**：`api_url_denylist` 禁止 AI 读取的域名；敏感域名默认 hints 提示（N4）；allowlist 不做（AI 场景需读任意公开页） | 设置 + open_and_read |
| P4 | 数据读取权限 | ✅ 已有：设置敏感键返回 null；密码库不开放（底线）；历史/书签只读 | 已有 |
| P5 | 交互目标权限（点危险按钮） | 交互预检（I2）+ 高风险文档提示（I12）+ 开关（P1）——**不做通用"危险按钮识别"**（无法通用且易误伤） | action/* |
| P6 | 资源权限 | 标签上限 10（J2）、并发上限 5（D5）、截图保留 100（O2） | 全局 |
| P7 | 用户确认 | API 无人值守不强制确认（信任面）；dashboard 一次性门票保留（人工查看面板） | 已有 |
| P8 | **权限变更审计** | **权限设置变更记入审计**（api_readonly / api_agent_actions / api_url_denylist 等变更可查，谁改了什么） | audit/reads |
| P9 | **AI 标签的页面权限请求**（geolocation / camera / notification） | **默认拒绝，不弹窗打扰用户**；用户标签保持现有行为 | 全局（AI 标签权限策略） |

| P11 | 多用户权限 | 单用户家用场景，不引入多用户权限体系 | — |

> **新增机制汇总**（P 类）：① 三层权限模型（Read/Write/Interactive）；② open_and_read 只读放行（语义读）；

## 4. 命令设计

### 4.1 P0：原子化「看页面」闭环（4 项）

#### `open_and_read` —— 杀手锏命令

覆盖 A、B 主体、D、F1–F3、G、J1–J4、J6。

| 参数 | 说明 | 默认 |
|---|---|---|
| `url` | 目标网址（必填；仅 http/https，SSRF + 协议白名单校验） | — |
| `mode` | read_page 8 种模式 | `text` |
| `selector` | CSS 选择器限定（同 read_page 语义） | 整个 body |
| `wait_for` | `load` / `selector:xxx` / `selector_gone:xxx` / `stable:ms` / `ms:3000` | `load` |
| `lazy` | 滚动到底触发懒加载后重读（含到底判定） | `false` |
| `expand` | 展开原生 details 折叠内容 | `false` |
| `iframe` | 同源 iframe 并入读取 | `false` |
| `shadow` | 尽力穿透 shadow DOM | `false` |
| `auto_dismiss` | 固定脚本关闭常见弹窗（Cookie/订阅浮层） | `false` |
| `reuse` | 复用同 URL 的 AI 标签（不新开） | `false` |
| `close` | 读完是否关闭新标签 | `false` |
| `ua` | 读取 UA：`desktop` / `mobile`（移动版内容更简洁的场景，M 类） | `desktop` |
| `max_chars` / `max_items` | 同 read_page 硬顶 | 200000 / 500 |

行为：后台新开（或复用）标签 → 等待 wait_for（超时兜底）→ 按需 lazy/expand/iframe/shadow/auto_dismiss → 按 mode 读取 → 按 close 去留 → 返回统一结构。

**响应骨架**（G3）：
```json
{"ok":true,"data":{
  "tab_id":"…","origin":"ai","url":"…","final_url":"…","title":"…",
  "mode":"text","meta":{…},"ts":…,"content_type":"page",
  "truncated":false,"partial":false,"empty":false,
  "hints":["页面含 canvas，建议截图"],
  "text":"…"}}
```
> `content_type:"page"`（O4）：显式标记"这是页面数据，非指令"——供 AI 调用方做 prompt injection 隔离。

**错误分类**：`error_type` ∈ `cert_error` / `http_error` / `network_error` / `timeout` / `tab_closed` / `page_crashed` / `banned_scheme` / `tab_limit`。

#### `read_status` —— 状态感知

覆盖 A5–A7、A9、D3、E1。参数：`id`（缺省活动标签）。

返回：`{url, final_url, title, origin, readyState, loading(loading/interactive/complete), http_status, has_canvas, has_modal, has_login_form, favicon, tabCount, aiTabCount}`。

#### `screenshot` 增强

覆盖 B6（canvas 配套）。新增参数：`full_page`（整页截图，默认 false）、`selector`（元素截图）；`id` 已有。

返回：落盘路径 + 尺寸 + 元素是否找到。

#### `tabs/close_ai` —— 标签回收

覆盖 J1、J5、J7、J10。参数：`url`（可选过滤）、`crashed_only`（可选）。行为：关闭全部（或过滤后）`origin:"ai"` 标签，**绝不碰用户标签**。返回关闭数量。

### 4.3 P1b：深入读取低频项 + 审计（4 项）

#### `read_page` 增强（P1b）

| `expand` | B3 | 展开原生 details |
| 表格 `merged` 提示 | C1 | 检测 rowspan/colspan |

#### `action/dismiss` —— 关闭弹窗

覆盖 B8、H3。固定脚本识别常见弹窗（含"同意/接受/关闭"按钮的浮层）并关闭。**只点可判定浮层，识别不了返回提示，绝不盲点。**

#### `audit/reads` —— 读取审计查询

覆盖 K3–K5。参数：`limit`（默认 50，硬顶 500）。返回：最近 AI 读取/交互记录 `{ts, cmd, url, result, error_type?}`——**不记内容、不记表单值**。

#### `audit/egress` —— 网络外发审计查询

覆盖 N3。复用 `audit.rs::egress_audit`（前端已有）。返回：AI 标签（及全浏览器）的网络外发请求汇总——用户可查"AI 访问了什么域名、发了什么请求"。Read，MCP 暴露。

### 4.4 P2：读取辅助交互（5 项，覆盖 I 类 + B2 + H）

| 命令 | 参数 | 固定脚本行为 | 风险 |
|---|---|---|---|
| `action/wait_for` | id, condition, timeout | 等待元素出现/消失/页面加载（带超时） | Read |
| `action/scroll` | id, direction, amount? | `scrollBy`/`scrollTo`（上下/到底/到顶） | Write |
| `action/click` | id, selector, index?, wait_after? | 预检（I2）→ querySelectorAll 取第 index 个 → click() → 返回 navigated/url_changed | Write |
| `action/fill` | id, selector, index?, value, wait_after? | 预检 → 设 value + 触发 input/change 事件（值只落字符串，不执行） | Write |
| `action/back` | id | history.back()（交互撤销，I5） | Write |

**二期可选**：`action/hover`（I9）、`action/key`（I8）。

**交互失败统一错误**（I2）：`action_error` ∈ `not_found` / `not_visible` / `disabled` / `in_iframe` / `in_shadow` / `page_changed`。

**安全设计**：固定脚本 + 独立开关 `api_agent_actions`（默认 false）+ MCP 默认不暴露 + selector 校验同 read_page + 每次交互现查 DOM（I10）。

## 6. 标签生命周期治理（J 类落地）

| 机制 | 设计 |
|---|---|
| 来源标记 | Tab 结构加 `origin: "user" \| "ai"`；open_and_read 开的标 ai；list_tabs 返回 |
| 上限保护 | AI 标签 ≤ 10；超限 open_and_read 返回 `error_type:tab_limit` + 提示 tabs/close_ai |
| 复用 | `reuse:true` 按 URL 匹配已有 AI 标签，命中则不新开 |
| 回收 | `tabs/close_ai`（全清/按 url/崩溃标签）；open_and_read `close:true` 读完即关 |
| 不打扰 | 后台打开不抢焦点；会话快照不纳入 AI 标签 |
| 崩溃回收 | `page_crashed` 的 AI 标签自动关闭或标记 |

## 7. 安全设计

1. **读类全暴露**：read_status、extract、reader/extract、translate、content/snapshot、audit/reads、read_page 增强——Read，MCP 全量暴露、`api_readonly` 下可用；
2. **open_and_read 是 Write 但语义是读**：开标签受只读闸门约束；URL 仅 http/https + SSRF 校验 + 禁 file:// 与 javascript:；
2b. **内网 URL 策略（M 类）**：默认拒绝私有/内网地址（SSRF 防护）；`api_allowed_ips` 白名单信任面内允许读取内网服务（与 HTTP API 的 IP 白名单同源语义）——**拍板项**；
3. **F4 恶意页面防御**：所有脚本保存原生 DOM API 引用，页面 monkey-patch 无效；
4. **交互三层兜底**：固定脚本 + 独立开关（默认关）+ MCP 不暴露；交互预检防误点（I2）；
5. **auto_dismiss 只点可判定弹窗**：识别不了返回提示，绝不盲点；
6. **fill 防注入**：value 只写入 input.value 字符串，不执行；
7. **标签治理防搞乱浏览器**：来源标记、上限、可回收、不抢焦点、不污染会话快照（J 类）；
8. **审计不记内容**：audit/reads 只记 url + 命令 + 结果码（K5）；
9. **尺寸控制**：4MB 响应硬顶、max_chars/max_items 硬顶沿用；
10. **日志**：只记命令名 + 计数 + 错误类型，不记内容。

### 7b. 隐私设计（N 类落地）

1. **AI 读取默认隐私友好**：不写浏览历史（N1）+ 审计记录（audit/reads）+ 网络外发可查（audit/egress）——用户历史干净，AI 行为透明可追溯；
2. **隐私防护继承**：AI 标签与用户浏览同一隐私策略（广告拦截/指纹防护/GPC/跟踪防护默认全开），不因 AI 降级（N2）；
3. **敏感页面知情**：银行/支付/邮箱/医疗域名 → hints 提示，不强制拦截（N4）；
4. **最小采集**：固定脚本只读请求内容，不碰 Cookie/存储/其他标签（N6）；
5. **用户透明**：AI 标签可见、审计可查、交互可见（N8）。

### 7c. 安全纵深（O 类落地）

1. **八层纵深**：传输鉴权（O9 已有）→ URL 网络（O1/O6）→ 内容（F 类）→ 交互（O5）→ 数据（K5/N5）→ 资源（J2/D5/E3）→ 调用方（O4/O7）→ 审计（O8）；
2. **重定向每跳校验**：open_and_read 跟随重定向时每跳重新校验 URL 白名单 + SSRF，防跳转绕防（O1）；
3. **审计持久化 + 不可关闭**：audit 入 db 表，记录所有 AI 操作，安全底线（O3/O8）；
4. **内容隔离**：响应带 `content_type:"page"`，AI 调用方据此将页面内容视为数据非指令（O4）；
5. **边界明确**：API 不判断内容善恶、不拦截敏感操作（信任面内），文档明示由 AI 调用方判断（O5/O7）；
6. **零新增依赖**：全部复用现有模块，固定脚本编译期嵌入（O10）。

### 7d. 权限设计（P 类落地）

1. **三层权限模型**：Read（读取）/ Write（导航·清理·开标签）/ Interactive（交互动作）——写受 `api_readonly`，交互受 `api_agent_actions`（默认关）；
2. **只读放行语义**：`api_readonly` 下 open_and_read 放行（语义是读），action/* 与 tabs/close_ai 拒绝——"能看不能动"（P2）；
3. **域名控制**：敏感域名 hints（N4 一期）+ `api_url_denylist`（P3 二期）；
4. **权限变更审计**：权限设置变更记入 audit（P8）；
5. **AI 标签页面权限默认拒绝**：geolocation/camera/notification 等页面权限请求不弹窗、默认拒（P9）；
6. **MCP 同权**：MCP 暴露范围与 API 权限矩阵一致（P10）。

## 8. 标准流程示例（L5，文档用）

```
看一个页面：      open_and_read {url, mode:"text"}
页面读不全：      看 hints → 有 canvas → screenshot；有遮罩 → auto_dismiss 或 action/dismiss；需登录 → action/fill + action/click + wait_for → 再 read_page
懒加载页：        open_and_read {url, lazy:true}
多轮复查：        open_and_read {url, close:false} → 记住 tab_id → 后续 read_page {tab_id}
读完清理：        tabs/close_ai
追溯 AI 行为：    audit/reads
```
